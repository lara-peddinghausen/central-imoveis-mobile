# Central de Imóveis - Aplicativo Móvel (Frontend)

## Sobre o Projeto
Este repositório armazena o Frontend Mobile do **Sistema de Administração de Imóveis para Locação**. Trata-se de um aplicativo móvel voltado para proprietários, administradores e pequenas imobiliárias gerenciarem seus imóveis de forma rápida, segura e na palma da mão.

> ⚠️ **Status do Projeto:** 🚧 Em Desenvolvimento

## Tecnologias e Ferramentas Utilizadas
* **Framework:** React Native
* **Plataforma de Desenvolvimento:** Expo
* **Linguagem:** JavaScript
* **Navegação:** Expo Router
* **Consumo de API:** Axios (Integrado com ViaCEP e Backend em Spring Boot)
* **Persistência Local:** AsyncStorage

## Funcionalidades em Implementação
* **Autenticação:** Telas de login e cadastro integradas ao Spring Security.
* **Painel Principal (Home):** Visualização rápida de imóveis separados por cartões dinâmicos indicando status ("Disponível" ou "Alugado").
* **Módulo de Contratos:** Cadastro de vigências contratuais, dados de inquilinos e acompanhamento de fluxo de hóspedes.
* **Módulo Financeiro:** Telas de lançamentos rápidos de receitas/despesas e renderização de gráficos estruturados de fluxo de caixa.
* **Gerenciamento de Perfil:** Atualização cadastral segura do administrador.
